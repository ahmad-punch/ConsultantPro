# Learnings

Things that were not obvious and cost time. Newest first. Each entry: what happened, why, what to do instead.

- **2026-10-21, Next 16 renamed middleware to proxy.** The file is `src/proxy.ts`, the function is `proxy`, the matcher export is still `config`. Proxy runs on the Node.js runtime by default and `runtime` cannot be set there. Keep it free of `next/headers` and DB imports; it only verifies the HMAC cookie via `src/lib/auth-token.ts`.
- **2026-10-21, Cache Components is on.** `cacheComponents: true` (with `partialPrefetching`) makes reading cookies, `searchParams` or uncached data outside `<Suspense>` a build error. Put session reads and DB queries in an async child component wrapped in `<Suspense>`, not at the top of a page or layout. Escape hatch per segment: `export const instant = false`.
- **2026-10-21, PGlite in Next dev.** PGlite is WASM and must not be bundled: `serverExternalPackages: ['@electric-sql/pglite']`. The client is a `globalThis` singleton so HMR does not reopen `.pglite/`. One process per data folder: stop `pnpm dev` before `pnpm db:seed`, or the folder can corrupt (fix: delete `.pglite/` and re-seed). `next build` without `DATABASE_URL` uses an in-memory PGlite because build workers run in parallel.
- **2026-10-21, PGlite schema is applied from `drizzle/` migrations.** The db client runs the migrator on first use and every query waits for it. After changing `schema.ts`, run `pnpm db:generate` and commit the SQL; never `drizzle-kit push` into `.pglite/` (it bypasses the migration journal).
- **2026-10-21, neon-http has no interactive transactions.** `db.transaction()` throws on Neon HTTP and `db.batch()` does not exist on PGlite. Write sequentially; for case numbers, retry once on unique violation (23505).
- **2026-10-21, NEXT_PUBLIC_ env vars must be referenced literally.** `process.env[name]` is not inlined into client bundles. `src/lib/pricing.ts` spells out each Stripe link variable for that reason.
- **2026-10-21, shadcn CLI v4 changes.** `init -d` uses the `radix-nova` style, the unified `radix-ui` package and the `cn` package (`src/lib/utils.ts` re-exports it). The `form` component is empty in this style; use `field` (Field, FieldLabel, FieldError, ...) with react-hook-form's `Controller`. pnpm 11 blocks esbuild's build script; `pnpm-workspace.yaml` allows it, otherwise shadcn and tsx installs fail.
- **2026-10-21, create-next-app and non-empty folders.** create-next-app refuses a folder that contains anything beyond a short allowlist (`_local/`, `.DS_Store` count as conflicts). Scaffold into a temp folder and copy in, then restore `.gitignore` entries.
- **2026-10-21, Bar Council rules shape the product.** Advocates cannot advertise or split fees with non-lawyers. The company sells information, intake, tracking and errands; advocates bill clients directly. Do not add features that route lawyer fees through the company without a decision record.
