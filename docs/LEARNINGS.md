# Learnings

Things that were not obvious and cost time. Newest first. Each entry: what happened, why, what to do instead.

- **2026-10-21, shadcn Sheet width needs the data-attribute variant to override.** `SheetContent` sets `data-[side=right]:w-3/4` and `sm:max-w-sm`; a plain `w-full` in `className` loses, so the help sheet was 281px wide on a 375px phone. Override with `data-[side=right]:w-full data-[side=right]:sm:max-w-md`.
- **2026-10-21, help anchors need a client scroll.** Help pages stream inside `<Suspense>`, so the browser's jump to `#section` fires before the heading exists. `src/components/admin/help/scroll-to-hash.tsx` scrolls once on mount. HelpButtons in a `PageHeader` outside `<Suspense>` are part of the prerendered shell, so their markdown body sits in a `'use cache'` component (`HelpMarkdown`).
- **2026-10-21, `outputFileTracingIncludes` keys are route globs matched with `contains`.** Next matches each key with picomatch `{ contains: true }` against the route path, so `"/*"` applies to every server route; values are globs from the project root. Fully static pages get no trace, which is fine because they read files at build time. Check the result in `.next/server/app/**/page.js.nft.json` after `pnpm build`.
- **2026-10-21, render repo markdown with `format: "md"`.** Docs such as the changelog contain `<Suspense>`, `{` and `<input>` in prose; compiled as MDX they fail. `src/components/admin/project/markdown.tsx` passes `options={{ mdxOptions: { format: "md" } }}` to `MDXRemote`, and renders one-line list items with a small inline renderer instead of one MDX compile per item.
- **2026-10-21, a form that its own action unmounts never sees the result.** With `useActionState` plus a `useEffect` for toasts and redirects, "Convert to case" converted the lead but neither toasted nor redirected: `revalidatePath` re-rendered the page in the same commit and replaced the form, so the effect never ran. `src/components/admin/action-form.tsx` now awaits the action inside `startTransition` and handles the result right after the `await`. It also submits via `onSubmit`, which stops React 19 resetting the inputs when validation fails.
- **2026-10-21, date-only fields are stored at 12:00 UTC.** `<input type="date">` values are saved as noon UTC (`parseDateInput` in `src/lib/validation/fields.ts`) and every panel date renders in UTC, so a date shows as the same day in the UK and Pakistan and server and browser agree. Compare dates by UTC day, not by timestamp (an unchanged date from a form is noon, a generated one may be midnight).
- **2026-10-21, Server Action files export only callable endpoints.** Every export of a `"use server"` file can be called from the browser. Shared helpers (like `insertCaseWithNumber`) live in `src/lib/actions/helpers.ts`, which is not a `"use server"` file, and every exported action calls `requireAdmin()` first.
- **2026-10-21, port 3000 may be another project.** On this machine port 3000 was a different app's dev server (with its own `/admin` redirect). The panel uses the `admin` config in `.claude/launch.json` (port 3200); never run two `pnpm dev` processes on the same `.pglite/` at once.
- **2026-10-21, `robots.ts` inside a route group is ignored.** `src/app/(marketing)/robots.ts` built without error but produced no `/robots.txt`; `sitemap.ts` and `opengraph-image.tsx` in the group do work. The public site ships `public/robots.txt` for now; a dynamic `robots.ts` must live at `src/app/robots.ts`.
- **2026-10-21, Radix Select shows a blank value for a preset default.** With a value set from `?category=` on first render, `SelectValue` rendered empty until the list was opened. Pass the label as `SelectValue` children (`{value ? LABELS[value] : undefined}`); the placeholder still shows when empty.
- **2026-10-21, MDX guides prerender fully with `generateStaticParams`.** Guide content is read with sync `fs` (memoised) and the MDX body sits in a `'use cache'` component, so every `/guides/[slug]` is static even though the page reads `params` inside `<Suspense>`.
- **2026-10-21, no typography plugin.** Guide prose is styled through `src/components/marketing/mdx-components.tsx` (per-element classes). Add new MDX elements there rather than reaching for `prose`.
- **2026-10-21, Next 16 renamed middleware to proxy.** The file is `src/proxy.ts`, the function is `proxy`, the matcher export is still `config`. Proxy runs on the Node.js runtime by default and `runtime` cannot be set there. Keep it free of `next/headers` and DB imports; it only verifies the HMAC cookie via `src/lib/auth-token.ts`.
- **2026-10-21, Cache Components is on.** `cacheComponents: true` (with `partialPrefetching`) makes reading cookies, `searchParams` or uncached data outside `<Suspense>` a build error. Put session reads and DB queries in an async child component wrapped in `<Suspense>`, not at the top of a page or layout. Escape hatch per segment: `export const instant = false`.
- **2026-10-21, PGlite in Next dev.** PGlite is WASM and must not be bundled: `serverExternalPackages: ['@electric-sql/pglite']`. The client is a `globalThis` singleton so HMR does not reopen `.pglite/`. One process per data folder: stop `pnpm dev` before `pnpm db:seed`, or the folder can corrupt (fix: delete `.pglite/` and re-seed). `next build` without `DATABASE_URL` uses an in-memory PGlite because build workers run in parallel.
- **2026-10-21, PGlite schema is applied from `drizzle/` migrations.** The db client runs the migrator on first use and every query waits for it. After changing `schema.ts`, run `pnpm db:generate` and commit the SQL; never `drizzle-kit push` into `.pglite/` (it bypasses the migration journal).
- **2026-10-21, neon-http has no interactive transactions.** `db.transaction()` throws on Neon HTTP and `db.batch()` does not exist on PGlite. Write sequentially; for case numbers, retry once on unique violation (23505).
- **2026-10-21, NEXT_PUBLIC_ env vars must be referenced literally.** `process.env[name]` is not inlined into client bundles. `src/lib/pricing.ts` spells out each Stripe link variable for that reason.
- **2026-10-21, shadcn CLI v4 changes.** `init -d` uses the `radix-nova` style, the unified `radix-ui` package and the `cn` package (`src/lib/utils.ts` re-exports it). The `form` component is empty in this style; use `field` (Field, FieldLabel, FieldError, ...) with react-hook-form's `Controller`. pnpm 11 blocks esbuild's build script; `pnpm-workspace.yaml` allows it, otherwise shadcn and tsx installs fail.
- **2026-10-21, create-next-app and non-empty folders.** create-next-app refuses a folder that contains anything beyond a short allowlist (`_local/`, `.DS_Store` count as conflicts). Scaffold into a temp folder and copy in, then restore `.gitignore` entries.
- **2026-10-21, Bar Council rules shape the product.** Advocates cannot advertise or split fees with non-lawyers. The company sells information, intake, tracking and errands; advocates bill clients directly. Do not add features that route lawyer fees through the company without a decision record.
- **2026-10-21, Route segment config and Cache Components.** `export const dynamic = "force-dynamic"` is a compile error with `cacheComponents` on, including in route handlers. Use `await connection()` from `next/server` to force request time. A page that calls `notFound()` inside `<Suspense>` streams the not-found UI with HTTP 200 (soft 404); fine for private pages that are noindex.
- **2026-10-21, Side effects after a server action.** Use `after()` from `next/server` for emails and other fire-and-forget work. A bare unawaited promise can be cut off on serverless when the response ends.
- **2026-10-21, NOT NULL columns on existing tables.** Drizzle's `$defaultFn` is a JavaScript-side default only. Adding a NOT NULL column with `$defaultFn` generates `ADD COLUMN ... NOT NULL` with no SQL default, which fails on any table that already has rows. Either add a SQL default (`.default(sql\`...\`)`) or patch the generated SQL to include `DEFAULT` before committing it.
- **2026-10-21, Admin action buttons before hydration.** `ActionForm` submits through `onSubmit`; clicked before the page hydrates (slow first compile in dev), the form falls back to a native GET and reloads with `?id=...` in the URL, dropping filters such as `?archived=1`. In browser tests, wait until the button has React props before clicking.

- **2026-10-21, No writable disk on Vercel.** The serverless filesystem is read-only except `/tmp`, so PGlite on `.pglite/` fails on a deploy without `DATABASE_URL`. Demo mode uses an in-memory PGlite instead, migrated from `drizzle/` at startup; that folder is not imported by code, so it must be listed in `outputFileTracingIncludes` or the migrator finds nothing. A module that the app imports must not run CLI side effects at load: `seed.ts` only calls `main()` when `process.argv[1]` is the seed script. See decision 0007.

## A client component using usePathname in a layout needs its own Suspense (2026-10-21)
`cacheComponents` prerenders dynamic routes; a tabs bar in `admin/network/layout.tsx` that called `usePathname()` failed `pnpm build` on `/admin/network/applications/[id]` ("URL data outside of <Suspense>") although dev worked. Wrap such client components in `<Suspense>` in the layout.
- **2026-10-28, dependencies installed but not declared.** An agent ran the PDF library install in a way that left it in node_modules but not in package.json or pnpm-lock.yaml, so the Vercel build failed with Module not found. Before pushing, run `rm -rf node_modules && pnpm install --frozen-lockfile && pnpm build` to reproduce the clean build Vercel does.
